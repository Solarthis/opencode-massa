# Independent verifier review

Baseline: 59ceacb634afd2d840cfed432e5bf2b4d5d05f18.

Improvements: ignore blank/non-string package scripts; redact complete captured output before shortening its tail; preserve UTF-8 characters across stream chunks; kill the verifier's own POSIX process group on timeout; discard an over-limit stream with an explicit diagnostic rather than retain a potentially incomplete secret; reject invalid timeout/output limits before launching anything.

The initial six regression tests all failed against the original implementation. The final suite has 73 passing tests, including nine new verifier checks. TypeScript compilation passes. Existing orchestration tests use a local fake OpenCode HTTP server. No OpenCode CLI, model provider, paid agent, real user workspace, live service or credentials were invoked. Live smoke and MCP end-to-end scripts were deliberately not run because they require a real provider.

The 200,000-character cap applies independently to stdout and stderr. Overflow intentionally omits that stream, losing diagnostics to avoid exposing a partially captured secret. Timeout process-group cleanup covers ordinary POSIX child processes; commands that deliberately detach into another session and native Windows behavior are not certified. Regex guards/redaction are heuristic, not a sandbox or comprehensive secret detector. Existing arbitrary shell-command execution semantics remain unchanged.

Run `npm ci --ignore-scripts` then `npm test`. Draft PR only; no merge, installation or deployment.
